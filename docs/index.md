# RDCore SDK Protocols
<sup>_Ce document est disponible en [français](index.fr.md)_</sup>

This site is the API reference of **RDCore.SDK.Protocols**, the messages a client exchanges with the [RDCore](https://github.com/rubberduck-vba/RDCore) platform, licensed under MIT and published on NuGet.

See the [API](xref:RDCore.SDK) section. The source is in [rubberduck-vba/RDCore.SDK.Protocols](https://github.com/rubberduck-vba/RDCore.SDK.Protocols). The language model and the plumbing every component of the platform shares are in the [RDCore.SDK reference](https://rubberduck-vba.github.io/RDCore.SDK/), and the user documentation of the platform is on the [RDCore site](https://rubberduck-vba.github.io/RDCore/).
