# RDCore SDK Protocols
<sup>_This document is available in [English](index.md)_</sup>

Ce site est la référence de l'API de **RDCore.SDK.Protocols**, les messages qu'un client échange avec la plateforme [RDCore](https://github.com/rubberduck-vba/RDCore), sous licence MIT et publiée sur NuGet.

Voir la section [API](xref:RDCore.SDK). Le code source se trouve dans [rubberduck-vba/RDCore.SDK.Protocols](https://github.com/rubberduck-vba/RDCore.SDK.Protocols). Le modèle du langage et la plomberie que partagent tous les composants de la plateforme sont dans la [référence de RDCore.SDK](https://rubberduck-vba.github.io/RDCore.SDK/), et la documentation de la plateforme pour ses utilisateurs, sur le [site de RDCore](https://rubberduck-vba.github.io/RDCore/).
